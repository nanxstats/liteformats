# Lightweight output formats for litedown

Provides HTML-first resume and cover-letter formats with self-contained
styling, local pages.js pagination, and optional PDF output through a
headless Chromium-based browser.

## Details

Start with
[`use_resume()`](https://nanx.me/liteformats/reference/use_resume.md) or
[`use_cover_letter()`](https://nanx.me/liteformats/reference/use_resume.md),
then render with
[`resume()`](https://nanx.me/liteformats/reference/resume.md) or
[`cover_letter()`](https://nanx.me/liteformats/reference/cover_letter.md).
